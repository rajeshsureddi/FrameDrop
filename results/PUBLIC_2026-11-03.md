- **S2 helps on every column.** It is weak alone, but adding it to DINOv2 gives +.011 to +.051 SRCC; the biggest gains are

- **Not yet shown:** that the synthetic pretraining is what makes S2 useful. Controlled runs (random-init S2, fresh fusion,
  both; and a synthetic quality-ranking stage) are running (Step 41).

## 3. VideoMAE-v2-S as motion features (Step 40 probe, partial)

Can a public video model replace or add to our motion encoder? Frozen features only, no training: **V2-S** = public
VideoMAE-v2 ViT-S/16 (OpenGVLab, Kinetics-710, distilled from ViT-g; no quality labels, no synthetic data), run on our
384×216 view of each clip (never upscaled), 16 frames = every 4th frame of 64-frame spans covering the clip; per view the
pooled last-block embedding + token std and block-6 token mean/std, averaged over spans ("pad" view = 224×384, black rows
added). **dla** = our dino_long_aug model as a frozen feature extractor (S1 = DINOv2-S tokens, S2 = our motion tokens,
fusion = pooled fusion feature; native + half scale). Regressor fit on LSVQ train only, applied unchanged to each test set
(x = cross-dataset; YT-UGC x here is also cross-dataset, unlike the FT column of table 1). PLCC / SRCC.
